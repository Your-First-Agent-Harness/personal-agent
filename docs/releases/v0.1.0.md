# personal-agent v0.1.0

发布日期：2026-12-05

第一周 G1 版本：提供可在全新目录安装并执行的 tarball，以及不需要 API Key、不请求网络的读 → 改 → 测试三工具 Demo。

## 安装

Release 资产：`personal-agent-0.1.0.tgz`。要求 Node.js 24 或更新版本，零运行时 npm 依赖。

在 tarball 所在目录执行：

```bash
RELEASE_DIR="$(mktemp -d /tmp/personal-agent-v010.XXXXXX)"
npm install --offline --ignore-scripts \
  --prefix "$RELEASE_DIR/install" \
  "$PWD/personal-agent-0.1.0.tgz"
(cd "$RELEASE_DIR/install" && ./node_modules/.bin/personal-agent demo)
```

机器可读验收输出：

```bash
(cd "$RELEASE_DIR/install" && ./node_modules/.bin/personal-agent demo --json)
```

完整说明见包内 `docs/install.md`。

## G1 能力

- 发布入口为编译后的 `dist/cli/main.js`，不再要求 Node 在 `node_modules` 中剥离 TypeScript。
- `personal-agent demo` 在独立 `/tmp` 工作区创建真实 `math.js` 与 `math.test.js`。
- 确定性离线脚本 ModelProvider 驱动真实 Agent Loop 与 `ToolRegistry`，不伪装实际模型、不请求网络。
- `read_file` 读取缺陷源码；`run_command` 证明修复前测试 `exitCode=1`；`edit_file` 实际把减法改为加法；再次 `run_command` 证明修复后 `exitCode=0`。
- 最后重新读取文件并断言最终内容，报告真实 diff、工具顺序、测试输出和临时目录清理状态。
- 包导出 `runAgentLoop`、`ToolRegistry`、`createBuiltinTools`、`runG1Demo` 与 `VERSION`，并包含 ESM JavaScript 和类型声明。

## 限制

- 离线 Demo 使用确定性脚本模型，只证明 Agent Loop 与真实工具链可安装、可执行，不证明外部模型的智能或稳定性。
- 普通 CLI 的真实模型调用需要用户自配 OpenAI 兼容 `baseUrl`、API Key 和模型名，并会产生相应网络请求。
- 本版本不包含 MCP，不提供进程恢复、托管运行等后续能力的发布级支持。
- 包仍为 npm `private`，发布渠道是 GitHub Release tarball，不是 npm registry。
- 本日未制作视频；没有 asciinema `.cast`、mp4、观看量或外部视频链接。仓库仅附真实终端输出与可复现命令。
