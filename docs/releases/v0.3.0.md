# personal-agent v0.3.0

发布日期：2027-01-12

## G3 阶段发布

v0.3.0 完成上下文工程、记忆边界、长任务状态和成本控制的第一版可验证基础。

## 新增能力

- 消息与工具 Schema 统一字符预算。
- 消息优先级、工具结果截断和确定性上下文压缩接口。
- TaskSummary、长期记忆准入/写入/检索/冲突检测。
- 100 轮状态机、无进展检测、恢复决策和任务计划。
- 成本核算、预算决策和 10/30/50/100 轮 Benchmark 汇总。
- G3 组件级综合验收。

## 验证

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run demo:d069
```

## 诚实边界

本版本的 G3 验收证明组件和确定性基线可运行，不伪造真实模型长任务成功率，也不宣称已经取得成本下降 40% 的外部证据。真实模型调用、生产价格和用户任务数据需要在后续受控环境中单独采集。
