## 怎么读这个仓库

```bash
git clone git@github.com:Your-First-Agent-Harness/personal-agent.git
cd personal-agent
git checkout D002   # 切到某一天，读该分支的 README
```

- 想看**某一天讲了什么**：切到对应分支，读 README。
- 想看**最新进度**：留在 `main`。
- 想看**某个决策为什么这么做**：`docs/adr/`。
