# Personal Agent

> 一个从零实现的 Agent Harness：工具可插拔、MCP 可互通、上下文可工程化、任务可编排、运行可观测、效果可评测，并提供 CLI、SDK 和可复现的发布验收。
>
> 这是一个按 100 天、每天一个独立分支推进的工程项目。每个 `Dxxx` 分支聚焦一个主题，包含实现、测试、Demo/脚本和说明；`main` 汇总已经合并的整体成果，并维护本索引。

## 项目能力概览

### Agent 基础能力

- OpenAI-compatible Model Provider 与流式响应
- 工具契约、Schema 校验、工具注册表和动态检索
- 文件读写、精确编辑、命令执行和安全边界
- MCP stdio Client/Server、文件系统适配和断线重连

### 上下文、记忆与长任务

- 上下文字符预算、消息优先级、确定性裁剪和工具结果截断
- 压缩接口、任务摘要、Schema 分组和压力测试
- 短期/任务/长期记忆边界、写入、检索、冲突和过期处理
- 任务状态机、计划、检查点、恢复策略、成本核算和预算降级

### 任务编排与可观测性

- 任务队列、后台 Runner、取消/暂停/恢复
- 子 Agent、并行编排、资源隔离和 DAG 依赖
- Run Store、幂等保护和未知副作用状态
- Trace/Span、Trace Store、Replay 执行器和 Eval 断言

### 产品化能力

- CLI 任务提交、状态查询、配置展示和工具能力清单
- 敏感工具审批、多租户隔离、数据保留和版本迁移
- 编程式 SDK、健康检查、部署文档和 API 兼容性检查
- 产品化清单、RC 审计、最终审计和正式发布验收

## 怎么读这个仓库

```bash
git clone https://github.com/Your-First-Agent-Harness/personal-agent.git
cd personal-agent
git checkout D050   # 切到某一天，阅读该分支 README
```

- 想看**项目整体进度**：留在 `main`，阅读本文件。
- 想看**某一天的实现和教学内容**：切到对应 `Dxxx` 分支，阅读该分支 README。
- 想看**某个决策为什么这么做**：查看 `docs/adr/` 和相关阶段文档。
- 想复现**最终发布验收**：运行 `npm run demo:d100`。

## 诚实证据边界

本项目的确定性测试和 Demo 用于证明组件契约、失败路径和可复现组合，不等同于真实模型智能、真实用户规模、真实成本下降、分布式生产可靠性或线上 SLO。相关能力需要独立的外部试验和生产数据。
