# Personal Agent

> 一个从零实现的 Agent Harness：工具可插拔、MCP 可互通、上下文可工程化、运行可观测、效果可评测。

**状态**：Day 1 / 100 · 未发布

---

## 为什么又从零写一个

现成框架能让你今天跑起来，但不会告诉你明天为什么坏。这个项目要回答三个问题：

1. **一次工具调用从模型输出到结果回填，中间到底发生了什么**——把每一步显式建模，而不是藏在框架里。
2. **上下文什么时候开始腐烂**——预算、裁剪、压缩、记忆，每一层都能被单独测量和替换。
3. **Agent 出错时从哪里查**——每一轮都有 trace，每一次失败都能重放。

不做的事：不做低代码平台，不做多模态，不做模型训练。
